EX716 Emacs Debug Line Following Mode

When single-stepping EX716 programs in the debugger, it is often useful to have the corresponding source line automatically highlighted in Emacs.

This Doc explains how the emacs hooks work, near the bottom you will find the combined lisp code that you paste into your .emacs file. 

This Emacs configuration adds a lightweight “follow mode” that watches debugger output and highlights the active .asm source line in a separate Emacs window as execution progresses.

This is not a full major mode and does not interfere with normal editing. It simply reacts to debugger output.

What This Does

When enabled:

The EX716 debugger prints lines of the form:

# filename.asm:123


Emacs watches the debugger output buffer (shell-mode or term-mode)

When a new source location is seen:

The corresponding file buffer is located

Emacs jumps to that line

The line is highlighted using hl-line-mode

The window recenters if needed

You can toggle this behavior on and off interactively.

Requirements / Assumptions
1. Debugger Output Format

This code expects debugger output lines matching:

# <filename>:<line-number>


Example:

# main.asm:417


If your EX716 debugger prints something different, you must adjust the regex in:

(string-match "# \\([^:]+\\):\\([0-9]+\\)" line)

2. Files Are Already Open in Emacs

The source file must already be loaded in Emacs:

(get-buffer latest-file)


This intentionally does not auto-open files to avoid surprises.

Installation

Add the following to your ~/.emacs or init.el.

You can paste this as-is. The sections are annotated below so you know what is safe to modify.

Step 1: Disable Default ASM Mode for EX716

Emacs’ built-in asm-mode is not well suited for EX716 assembly syntax.
This forces .asm files to open in text-mode instead.

(add-to-list 'auto-mode-alist '("\\.asm\\'" . text-mode))
(add-hook 'text-mode-hook
          (lambda ()
            (setq indent-tabs-mode nil)))


You may remove this section if you already use a custom EX716 mode.

Step 2: Debug Follow Configuration Variables
(defvar my-debug-output-queue "")
(defvar my-debug-output-timer nil)
(defvar my-debug-output-accumulator "")
(defvar my-debug-follow-enabled t)


my-debug-follow-enabled
Controls whether source following is active.

The other variables manage buffered async output safely.

You normally do not need to modify these.

Step 3: Toggle Command
(defun toggle-debug-follow ()
  "Toggle live source-line following during debug output."
  (interactive)
  (setq my-debug-follow-enabled
        (not my-debug-follow-enabled))
  (message "Debugger follow %s"
           (if my-debug-follow-enabled
               "enabled"
             "disabled")))


Use:

M-x toggle-debug-follow


This is useful when scrolling or editing during a debug session.

Step 4: Process Output Interception

This code safely intercepts output from either:

shell-mode

term-mode

and passes it through unchanged before inspecting it.

(defun my-debug-output-handler (proc string)
  (cond
   ((derived-mode-p 'shell-mode)
    (comint-output-filter proc string))
   ((derived-mode-p 'term-mode)
    (term-emulate-terminal proc string)))

  (setq my-debug-output-queue
        (if (> (length my-debug-output-queue) 5000)
            string
          (concat my-debug-output-queue string)))

  (my-debug-output-schedule-process))


This avoids breaking normal terminal behavior.

Step 5: Source Line Highlighting

When a new location is detected, Emacs:

Moves to the source line

Enables hl-line-mode

Recenters if needed

(hl-line-mode 1)
(set-face-attribute 'hl-line nil
                    :background "white"
                    :foreground "black")

Customization

You may prefer a darker theme:

;; Example alternative:
(set-face-attribute 'hl-line nil
                    :background "blue"
                    :foreground "white")


Only one of these should be active.

Step 6: Attach to Debugger Buffers

These hooks attach the handler automatically when a debugger starts:

(add-hook 'shell-mode-hook
          (lambda ()
            (add-hook 'comint-output-filter-functions
                      #'ansi-color-process-output nil t)
            (my-debug-attach-filter)))

(add-hook 'term-mode-hook #'my-debug-attach-filter)
(add-hook 'term-exec-hook #'my-debug-attach-filter)


This allows both shell and term-based debugger sessions.

How to Verify It Works

Open your .asm file in Emacs

Start the EX716 debugger in a shell or term buffer

Single-step until you see output like:

# main.asm:123


The source window should jump and highlight that line

If nothing happens:

Ensure the file buffer name exactly matches the printed filename

Confirm the debugger output format matches the regex

Known Limitations

Does not auto-open source files

Only tracks the most recent location

Assumes line numbers are 1-based

No breakpoint visualization (line highlight only)

All of these are intentional to keep the implementation simple and robust.

Technical Notes (for Lisp-savvy Readers)

Output is buffered to avoid reentrancy issues

A timer coalesces rapid debugger output

Partial lines are preserved correctly

The process filter does not interfere with ANSI color handling

No advice or mode redefinition is used

This is deliberately conservative Lisp.

;;; ================================================================
;;; EX716 Emacs Debug Source-Line Following
;;;
;;; Highlights the active source line in an .asm buffer while
;;; single-stepping the EX716 debugger in shell or term mode.
;;;
;;; Expected debugger output format:
;;;   # filename.asm:123
;;; ================================================================


;;; ------------------------------------------------
;;; Treat .asm as text (disable default asm-mode)
;;; ------------------------------------------------

(add-to-list 'auto-mode-alist '("\\.asm\\'" . text-mode))

(add-hook 'text-mode-hook
          (lambda ()
            (setq indent-tabs-mode nil)))


;;; ------------------------------------------------
;;; Debug follow state
;;; ------------------------------------------------

(defvar my-debug-output-queue "")
(defvar my-debug-output-timer nil)
(defvar my-debug-output-accumulator "")
(defvar my-debug-follow-enabled t)


(defun toggle-debug-follow ()
  "Toggle live source-line following during debug output."
  (interactive)
  (setq my-debug-follow-enabled
        (not my-debug-follow-enabled))
  (message "Debugger follow %s"
           (if my-debug-follow-enabled
               "enabled"
             "disabled")))


;;; ------------------------------------------------
;;; Output scheduling (coalesce async output)
;;; ------------------------------------------------

(defun my-debug-output-schedule-process ()
  "Schedule periodic processing of accumulated output."
  (unless my-debug-output-timer
    (setq my-debug-output-timer
          (run-with-timer
           0.2 0.2
           (lambda ()
             (when (> (length my-debug-output-queue) 0)
               (let ((data my-debug-output-queue))
                 (setq my-debug-output-queue "")
                 (my-debug-process-output data)))
             (when (string-empty-p my-debug-output-queue)
               (cancel-timer my-debug-output-timer)
               (setq my-debug-output-timer nil)))))))


;;; ------------------------------------------------
;;; Unified process output handler
;;; ------------------------------------------------

(defun my-debug-output-handler (proc string)
  "Intercept process output for shell or term modes."

  ;; Pass output through normally
  (cond
   ((derived-mode-p 'shell-mode)
    (comint-output-filter proc string))
   ((derived-mode-p 'term-mode)
    (term-emulate-terminal proc string)))

  ;; Accumulate output
  (setq my-debug-output-queue
        (if (> (length my-debug-output-queue) 5000)
            string
          (concat my-debug-output-queue string)))

  (my-debug-output-schedule-process))


;;; ------------------------------------------------
;;; Parse debugger output and follow source
;;; ------------------------------------------------

(defun my-debug-process-output (output)
  "Process debugger output and move highlight to current source line."

  (setq my-debug-output-accumulator
        (concat my-debug-output-accumulator output))

  (let* ((lines (split-string my-debug-output-accumulator "\n"))
         (last-line (car (last lines)))
         (latest-file nil)
         (latest-line nil))

    ;; Look for:  # filename.asm:123
    (dolist (line lines)
      (when (string-match "# \\([^:]+\\):\\([0-9]+\\)" line)
        (setq latest-file (match-string 1 line))
        (setq latest-line (string-to-number (match-string 2 line)))))

    (when (and latest-file latest-line my-debug-follow-enabled)
      (let ((buf (get-buffer latest-file)))
        (when-let ((win (get-buffer-window buf)))
          (with-selected-window win
            (goto-char (point-min))
            (forward-line (1- latest-line))

            ;; Highlight current line
            (hl-line-mode 1)
            (set-face-attribute 'hl-line nil
                                :background "white"
                                :foreground "black")
            ;; Alternative:
            ;; (set-face-attribute 'hl-line nil :background "blue" :foreground "white")

            (unless (pos-visible-in-window-p)
              (recenter))
            (redisplay))))))

  ;; Preserve partial trailing line
  (if (string-suffix-p "\n" my-debug-output-accumulator)
      (setq my-debug-output-accumulator "")
    (setq my-debug-output-accumulator last-line)))


;;; ------------------------------------------------
;;; Attach handler to shell / term buffers
;;; ------------------------------------------------

(defun my-debug-attach-filter ()
  "Attach unified process filter for shell or term modes."
  (let ((proc (get-buffer-process (current-buffer))))
    (when proc
      (set-process-filter proc #'my-debug-output-handler))))


(add-hook 'shell-mode-hook
          (lambda ()
            (add-hook 'comint-output-filter-functions
                      #'ansi-color-process-output nil t)
            (my-debug-attach-filter)))

(add-hook 'term-mode-hook #'my-debug-attach-filter)
(add-hook 'term-exec-hook #'my-debug-attach-filter)

;;; End of EX716 debug follow configuration
