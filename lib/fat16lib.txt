Handling End of a Multi-Cluster File
In FAT16, the end of a file's cluster chain is marked by a special end-of-cluster-chain marker. Typically, this marker is any value from 0xFFF8 to 0xFFFF.

To report that the end of a multi-cluster file has been reached, the GetNextCluster function should check if the value read from the FAT is within this range. If it is, the function should return a special value (e.g., -1) to indicate the end of the chain.

Allocating a New Cluster for Expanding a File
When expanding a file, you need to find a free cluster to allocate. In FAT16, a cluster is considered free if its entry in the FAT is 0x0000.

int AllocateCluster() {
    // Calculate the start and end of the FAT area
    int fatStart = ReservedSectorsCount;
    int fatEnd = fatStart + SectorsPerFat;
    
    // Iterate over each FAT sector
    for (int sector = fatStart; sector < fatEnd; sector++) {
        // Read the FAT sector into a buffer
        uint8_t* buffer = ReadBuffer(DiskID, sector);
        
        // Check each FAT entry in the sector
        for (int i = 0; i < BytesPerSector; i += 2) {
            int16_t* entry = (int16_t*)(buffer + i);
            if (*entry == 0x0000) {
                // Mark this cluster as the end of the chain
                *entry = 0xFFF8;
                
                // Write the updated FAT sector back to disk
                WriteBuffer(DiskID, sector, buffer);
                
                // Free the buffer
                FreeHeap(buffer);
                
                // Return the newly allocated cluster number
                return ((sector - fatStart) * (BytesPerSector / 2)) + (i / 2);
            }
        }
        
        // Free the buffer
        FreeHeap(buffer);
    }
    
    // No free clusters available
    return -1;
}

    int bytesRemaining = length;

    while (bytesRemaining > 0) {
        // Write current cluster
        WriteCluster(currentCluster, dataPtr);
        
        // Update pointers and counters
        dataPtr += BytesPerSector * SectorsPerCluster;
        bytesRemaining -= BytesPerSector * SectorsPerCluster;

            if (nextCluster == -1) {

                if (nextCluster == -1) {

                UpdateFatEntry(currentCluster, nextCluster);
            }
            
            // Move to the next cluster
            currentCluster = nextCluster;

}
